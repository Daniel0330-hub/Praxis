# Praxis知行伴学 AI 成本面板与试运行准备

版本：v1.0  
日期：2026-10-31

## 1. 本轮结论

产品首页已经增加 AI 成本与运行状态面板。用户可以直接看到产品路径当天是否调用模型、使用多少 token、生成多少缓存，以及当前模型和路由策略。

## 2. 面板指标

- 今日产品 AI 调用数 / 每日上限；
- 输入 tokens / 输出 tokens；
- 本地讲解缓存条目数；
- 提供方；
- 模型；
- 调用策略；
- 密钥是否已配置。

面板只返回 `api_configured: true/false`，不会返回、截取或展示 API 密钥。

## 3. 当前状态

浏览器验收结果：

- 知识节点：16；
- 平均置信度：6%；
- 已记录作答：5；
- 今日产品 AI 调用：0/5；
- 产品输入/输出 tokens：0/0；
- 本地讲解缓存：0；
- AI：OpenAI；
- 模型：GPT-6 Luna；
- 策略：selective；
- 密钥：已配置。

离线评估调用不写入产品使用表，因此面板的 0/5 表示真实学习产品尚未触发付费讲解，而不是此前没有运行模型评估。

## 4. 试运行规则

实际学习时：

1. 第一次答错使用本地规则，面板调用数不增加；
2. 同一知识点再次答错才调用 Luna；
3. 成功调用后记录 token，并缓存合规讲解；
4. 相同输入再次出现时读取缓存，不增加请求数；
5. 达到 5 次日上限后全部使用本地规则；
6. 模型异常不重试，直接回退。

## 5. 验收结果

当前共发现 19 项测试：17 项通过，2 项真实课程扩展测试默认跳过。新增测试确认状态接口不会暴露 API key。

下一步可以开始真实单用户试学习。先正常做题，不需要为了测试而故意答错；系统会在自然发生的重复错题上触发最多 5 次 Luna 调用。
