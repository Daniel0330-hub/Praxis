# Praxis知行伴学｜项目日志

更新日期：2026-10-31

## 项目目标

建设以自主理解和练习为核心的课程伴学系统。课程资料按 syllabus、课件、作业与可合法访问的教材资料分层处理；知识点讲解须区分课程证据、自编解释与外部资料，练习按知识点归类并根据作答反馈调整。

## 已完成的工作

1. 完成需求调研、需求分析、产品方案、AI 方案与 MVP 的分阶段文档；工程里程碑见 `23` 至 `32` 号文档。
2. 搭建本地 FastAPI 与网页 MVP，包含 Dashboard、课程概览、知识地图、题目归类、课程问答、自主测验、Timeline 和 Settings。
3. 接入六门课程的目录与已收集资料，课程详情展示已核验的 syllabus 信息、资料清单和知识点。公开教材资料按可访问范围使用；仅有书目或目录时，不视为已读取教材正文。
4. 将知识点与作业材料、练习变式及学习反馈关联；保留题目匹配状态和课程证据来源。课程覆盖与题目质量仍需逐课程复核。
5. Dashboard 的六门课程采用不同主题色，课程页与 Timeline 延续对应颜色。Timeline 仅显示考试和 Project 事件，不显示普通上课日期及一般作业。
6. Settings 的提醒开关、AI 讲解开关、界面语言与每日模型调用上限已接入持久化。每日上限实际约束模型调用，达到限额后回退本地讲解；中英文切换作用于导航和主要界面文案。
