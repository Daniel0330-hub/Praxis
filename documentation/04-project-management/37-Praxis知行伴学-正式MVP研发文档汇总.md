# Praxis知行伴学：正式 MVP 研发文档汇总（公开终版）

## 产品目标

将课程平台中的 syllabus、课件、教材与作业转化为以“理解—检验—纠错—迁移”为主线的自主学习系统。

## 真实研发范围

6 门真实课程；295 份材料、5,217 页/切片；135 个知识节点，其中 115 个已绑定来源；114 道练习题；24 项自动化测试通过。

## 真实数据获取

用户每次确认登录 CourseWorks 并完成 Duo。Agent 仅在已授权会话中只读识别 STAT/MATH 课程、遍历目录并下载课程包；系统不存储密码或持久 Token。Canvas OAuth2/REST API 连接器完成方案设计，但未在缺少 Developer Key 的条件下宣称已生产化。

## 数据处理与建模

1. 识别 syllabus、课件、教材、作业与答案角色；
2. 页级解析并保留课程、文档与页码元数据；
3. 从 syllabus 提取课程目标、教材线索与关键事件；
4. 将课件知识点与教材对应区间联合建模；
5. 构建交互知识地图并为节点绑定来源；
6. 将作业逐题匹配知识点，形成同构题、迁移题与退出测试。

## AI 产品闭环与 POC

课程问答必须返回来源页码，证据不足时拒答；自适应练习诊断薄弱点、定向出题、批改、反馈与退出判断。POC-1 验证解析与知识地图；POC-2 验证可信问答；POC-3 验证诊断和练习闭环。OpenAI Responses API 与结构化输出完成小样本真实调用验证。

## 当前产品

Dashboard 按课程进入课程概览、知识地图、课程问答和测验；Timeline 聚合考试和 Project；设置支持提醒联动、中英文切换与每日 AI 调用上限。

## 公开展示边界

保留真实课程身份、数据规模、研发过程与技术决策；不公开教师/学生身份、联系方式、个人成绩、密钥、原始课件、教材全文和作业答案。
