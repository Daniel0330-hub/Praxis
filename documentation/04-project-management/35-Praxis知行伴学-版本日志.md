# Praxis知行伴学｜版本日志

更新日期：2026-10-31

> 当前为本地 MVP。以下编号用于产品迭代记录；API 的技术版本仍为 `0.1.0`，尚未发布正式安装包。

## MVP 迭代 2026.10.31-c｜设置联动

- “每日模型调用上限”改为可选并可保存，提供 0、1、3、5、10、20、50 次/日；模型调用读取保存值，达到上限后使用本地讲解。
- 修复语言设置只保存不生效的问题。保存后立即切换导航、主要页面文案与日期格式，刷新后仍保留选择。
- 验证：浏览器中英往返切换；23 项单元测试通过，2 项跳过。

## MVP 迭代 2026.10.31-b｜课程主题与 Timeline

- 六门课程设置固定且不同的主题色，应用于 Dashboard 卡片、课程页和 Timeline。
- Timeline 仅保留考试及 Project 发布/截止时间；移除上课日期与普通作业。新增考试/Project 筛选和课程颜色图例。
- 未明确考试时间的事件显示“时间待确认”，避免把占位时间误认为真实考试时间。
- 提醒开关关闭时，Dashboard 和 Timeline 同步隐藏这些事件。

## MVP 迭代 2026.10.31-a｜自主学习界面与课程内容

- 将工程验证页面改为以课程自主学习为中心的 Dashboard、Timeline、Settings 和课程内导航。
- 提供课程概览、交互式知识地图、知识点详情、课程问答、题目归类和自主测验入口。
- 将已收集的课程 syllabus、课件、作业及可访问的外部资料按来源呈现；教材正文获取状态与公开目录、摘要分开标记。

## 版本边界

- 页面显示六门课程，不等于六门课程的教材正文、每一道作业题或全部考试安排均已完整核验。
- 本记录汇总当前可见的 MVP 迭代，不追溯伪造此前每一次代码变更的精确时间与版本号。
