> 将 Canvas / CourseWorks 中分散的 syllabus、课件、教材与作业，重建为可追溯知识地图、证据约束问答和自适应练习闭环。

## 项目不是只做了一个页面

这是一个从需求调研开始的独立 AI 产品研发案例，覆盖需求调研、竞品分析、立项、MVP、产品方案、AI 技术方案、正式 PRD、三轮 POC、真实课程数据处理、评估测试、项目日志和版本日志。

`用户授权 Canvas 会话 → Agent 辅助课程采集 → 文档角色分类 → 页级解析/索引 → syllabus 与课件/教材联合建模 → 知识地图 → RAG 问答 → 作业归类与仿题 → 自适应练习`

## Canvas / Agent 接入实况

- 使用 Columbia CourseWorks（Canvas）真实登录会话；
- 用户每次确认登录并亲自完成 Duo，不保存密码或持久 Token；
- Agent 在已授权会话中只读识别 STAT/MATH 课程、遍历文件并下载课程包；
- Canvas OAuth2 / REST API 连接器已完成方案设计，但受 Developer Key 与 Duo 条件限制未生产化；
- 保留人工导出/上传作为失败兜底。

## 已实现功能

- 课程 Dashboard 与跨课程 Timeline；
- 可进入定义、公式、应用、来源和练习的交互知识地图；
- 页级检索、引用展示和证据不足拒答；
- 作业知识点归类、同构仿题、批改、错因反馈、迁移题和退出测试；
- 规则优先、检索缓存、选择性模型调用、每日上限与降级策略；
- 中英文界面、设置联动与课程主题色。

## AI 方案与验证

POC-1 验证课件解析、公式恢复与知识地图；POC-2 验证可信问答、引用与拒答；POC-3 验证诊断、定向微练习、迁移题与退出测试。正式版接入 OpenAI Responses API 与结构化输出，并采用本地规则、缓存与分级调用压低成本。

## 公开版与正式版的区别

公开 MVP 保留真实课程结构、节点数量、产品交互和研发统计；课件正文、原始作业、教师/学生联系方式、个人成绩、密钥与教材全文不公开，页面解释、题目、日期和回答使用脱敏样例。正式本地版使用课程证据库和模型 API。
